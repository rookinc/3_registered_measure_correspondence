# Registered Measure Correspondence

Program 03 of the Quantum Relativity research program.

## Starting point

Program 02 closed the algebraic EPR assembly.

Its terminal interface is

    P_odd
      -> Gamma
      -> w_ab
      -> CHSH = 1 + 3/sqrt(5) > 2.

The finite construction derives a unique positive normalized algebraic measure

    w_ab = (1 + a b Gamma) / 4.

Program 03 does not reconstruct that result.

It begins from it.

## Primary question

How does a canonical positive algebraic measure become registered empirical
frequency?

The distinction to preserve is

    algebraic measure
      !=
    finite state count
      !=
    observed frequency.

Program 02 derives the first.

Program 03 investigates the bridge to the third.

## Motivation

The nontrivial Program-02 weights contain sqrt(5).

They therefore cannot be represented exactly as finite equal-count ratios.

A finite deterministic periodic orbit likewise produces rational limiting
visit frequencies.

The correspondence problem is therefore not solved by counting hidden source
states.

The apparatus must supply additional registered structure.

Possible mechanisms include:

- evolving finite history,
- repeated relational encounters,
- algebraic transition weights,
- nonperiodic registered dynamics,
- induced invariant measures,
- asymptotic frequencies,
- or another native finite process that does not collapse to static counting.

These are candidates, not assumptions.

## Required output

The program should determine whether finite registered mechanics supplies a
law of the form

    canonical algebraic weight
      -> registered repeated-trial frequency.

A successful construction must explain why the empirical frequency attached
to an outcome class converges to the algebraic measure already fixed by the
finite relational geometry.

## Attack conditions

The program fails if correspondence requires inserting the target frequencies
by hand.

It also fails if the only available mechanism is:

- finite equal-count hidden-state counting,
- setting-dependent source weighting,
- postselection after measurement settings are chosen,
- remote-setting dependence in local response rules,
- or an assumed Born frequency rule with no finite provenance.

## Program-02 interface

The imported algebraic facts are:

    Gamma(A,B)
      =
    Tr[P_odd (A tensor B)]

and, on traceless local observables,

    Gamma(A,B)
      =
    -1/2 Tr(AB).

Native analyzer geometry gives

    v = 1/sqrt(5).

For binary outcomes,

    w_ab
      =
    (1 + a b Gamma) / 4.

The frozen quartet gives

    CHSH
      =
    1 + 3/sqrt(5).

These are inputs to Program 03, not targets to be rediscovered.

## Initial theorem target

Identify the weakest native repeated-event structure that can support an
irrational algebraic invariant measure while preserving finite registered
state and explicit receipt history.

Then test whether the Program-02 weights arise from that structure without
being inserted as transition probabilities.

## Research boundary

This is a correspondence program.

It does not reopen the algebraic EPR construction.

It does not claim that empirical quantum frequencies have already been
derived.

The object under attack is the bridge between finite registered mechanics and
observed statistical frequency.
